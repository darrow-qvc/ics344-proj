# 5. Testing: repeatable commands and expected outputs

Answers feedback item 5 and the "repeatable test commands" half of item 6.

## 5.1 Running everything

```sh
make            # builds build/minish (and a stripped copy)
make test       # golden suite + pty job-control suite
BASH_PARITY=1 tests/run_tests.sh build/minish   # also compare each case against bash
make debug && tests/run_tests.sh build-debug/minish   # ASan + UBSan build
```

Expected final lines:

```
passed: 16  failed: 0          (26 with BASH_PARITY=1)
12 tests, 0 failed
```

## 5.2 Golden suite (`tests/run_tests.sh`)

Each `tests/cases/NN_name.sh` is piped into the shell from a fresh temp
directory with `HOME=/`; stdout+stderr and `status=N` are compared with
`NN_name.expected`. Cases not tagged `# nobash` are also run through
`/bin/bash` when `BASH_PARITY=1`; after replacing bash's `bash: line N:`
prefix with `minish:`, the outputs must be byte-identical. This is the
"output matches bash for all supported features" metric from the
proposal, turned into a pass/fail check.

| case | covers (feedback item) |
|---|---|
| 01_basic | words, quoting, escaping, comments (1) |
| 02_builtins | cd variants and errors, exit code (6) |
| 03_redirect | `> >> <`, missing files, collision table, redirection vs pipe, built-in redirection (4) |
| 04_pipeline, 05_pipeline_status | 2 to 8 stage pipelines, status of last command (4, 5) |
| 06_errors | nonexistent commands in all positions, 126/127 classes (5, 6) |
| 07_syntax | every syntax error message (1) |
| 08_jobs | `&`, `jobs` states Running/Done/Exit n, fg/bg errors (5) |
| 09_fdleak | `ls /proc/self/fd` in first/middle/last stage, with redirections (4) |
| 10_quick_exit | eight `true &` and 3 four-stage `true` pipelines: children exit before registration (3, 5) |
| 11_limits, 12_longline, 16_redir_limits | pipeline, line length and redirection limits (1) |
| 13_exit_status, 14_exit_args, 15_builtin_in_pipeline | exit semantics, built-ins forked inside pipelines (6) |

## 5.3 Interactive suite (`tests/pty_tests.py`)

Runs the shell inside a pseudo-terminal so Ctrl+C/Ctrl+Z are generated by
the tty driver, and inspects `/proc` and `tcgetpgrp()` from outside.

| test | asserts |
|---|---|
| ctrl_z_stops_only_foreground_job | child state `T` in `/proc`, `[1]+ Stopped` printed, shell owns the tty again |
| bg_resumes_stopped_job | `bg` prints `[1]+ sleep 30 &`, child state `S`, `jobs` says Running |
| fg_then_ctrl_c_kills_only_the_job | during `fg` the tty owner is not the shell; after Ctrl+C the job is gone, the shell is alive |
| ctrl_c_at_prompt_does_not_kill_shell | |
| background_done_notification | `[1] pid` on start, `[1]+ Done` before the next prompt |
| stopped_pipeline_resumes_with_terminal | `cat \| tr` stopped (both `T`), `fg`, typed text comes back upper-cased, Ctrl+D ends it |
| external_sigstop_on_background_job | SIGSTOP from outside shows Stopped, `bg %1` resumes, SIGTERM shows `Terminated` |
| quick_exiting_children_leave_no_zombies | 30 `true &` + 20 `true \| true \| true`, no `Z` state children, empty `jobs` |
| shell_leaks_no_descriptors | fd count of the shell identical after 40 pipelines/redirections including failing ones |
| job_numbering_and_fg_by_id | `+`/`-` markers, `fg %1`, `fg: current: no such job`, `fg: %7: no such job` |
| exit_warns_about_stopped_jobs | `There are stopped jobs.` once, second `exit` leaves |
| nonexistent_command_in_foreground_restores_terminal | tty owner is the shell after a 127 failure, alone and in a pipeline |

## 5.4 Manual demo script

```
minish> sleep 30 &            -> [1] 1234
minish> jobs                  -> [1]+  Running                 sleep 30 &
minish> sleep 40              (press Ctrl+Z)
                              -> [2]+  Stopped                 sleep 40
minish> bg                    -> [2]+ sleep 40 &
minish> fg %1                 -> sleep 30   (press Ctrl+C, prompt returns)
minish> cat f | sort | uniq
minish> sort < in.txt > out.txt
minish> ls >                  -> minish: syntax error near unexpected token `newline'
minish> ps -o pid,stat,cmd --ppid $$     (from ANOTHER terminal: no Z entries)
minish> exit
```

## 5.5 Memory and descriptor tools

- `make debug` builds with `-fsanitize=address,undefined`; the whole golden
  suite must pass under it with no sanitizer output.
- `valgrind --leak-check=full --track-fds=yes build/minish tests/cases/04_pipeline.sh`
  expected: `definitely lost: 0 bytes`, open descriptors at exit: 0, 1, 2 (+ the script fd).
- `strace -f -c build/minish bench/results/work/w_exec.sh` gives the
  syscall count per command used in docs/06.
